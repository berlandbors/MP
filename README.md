# Менеджер паролей

Безопасный менеджер паролей с ретро-консольным интерфейсом, работающий прямо в браузере без серверной части.

## Описание проекта

Приложение позволяет безопасно хранить логины и пароли от различных сервисов прямо в браузере. Все данные шифруются с помощью мастер-пароля и хранятся локально — никакие данные не передаются на сервер.

## Основные возможности

- 🔐 Защита мастер-паролем (SHA-256 хэш)
- ➕ Добавление записей (сервис, логин, пароль)
- ⚡ Генерация случайных надёжных паролей
- 🔍 Поиск по названию сервиса
- 📋 Копирование пароля в буфер обмена
- 🗑️ Удаление отдельных записей и полная очистка данных
- 💾 Экспорт в зашифрованный JSON-файл
- 📥 Импорт из зашифрованного JSON
- 📂 Импорт паролей из Chrome (CSV-формат)
- 📊 Отображение занятого места в LocalStorage

## Технологии

- **HTML5** — структура приложения
- **CSS3** — стилизация с ретро-консольным дизайном
- **JavaScript (ES2020+)** — вся логика приложения
- **Web Crypto API** — шифрование AES-GCM и PBKDF2
- **PWA (Progressive Web App)** — работа офлайн, установка как приложение
- **Service Worker** — кэширование для офлайн-режима
- **LocalStorage** — локальное хранение данных

## Безопасность

- **Мастер-пароль** хэшируется алгоритмом SHA-256 и сохраняется в LocalStorage. Сам пароль не хранится.
- **Шифрование AES-GCM (256 бит)** применяется при экспорте/импорте данных.
- **PBKDF2** (100 000 итераций, SHA-256) используется для получения ключа шифрования из мастер-пароля.
- Данные хранятся **только локально** в браузере — никакой передачи на сервер.

## Установка и использование

### Как открыть приложение

Откройте файл `index.html` в любом современном браузере или разместите файлы на веб-сервере.

### Создание мастер-пароля при первом запуске

При первом запуске приложение предложит установить мастер-пароль. Введите надёжный пароль (рекомендуется минимум 8 символов) и нажмите «Войти». Этот пароль защищает все ваши данные — **восстановить его невозможно**, обязательно запомните или запишите.

### Добавление паролей

1. Нажмите кнопку **«Добавить»**.
2. Заполните поля: название сервиса, логин, пароль.
3. Нажмите **«Сохранить»**.

### Генерация паролей

В окне добавления записи нажмите **«Генерировать»** — будет создан случайный пароль длиной 12 символов.

### Поиск по сервисам

Введите название сервиса в поле поиска — список паролей будет отфильтрован в реальном времени.

### Экспорт данных (JSON с шифрованием)

Нажмите **«Скачать JSON»**, введите мастер-пароль для шифрования — файл `passwords_encrypted.json` будет сохранён на ваше устройство.

### Импорт данных (JSON с шифрованием)

Нажмите **«Загрузить JSON»**, выберите ранее сохранённый файл, введите мастер-пароль для расшифровки.

### Импорт из Chrome CSV

1. В браузере Chrome откройте `chrome://settings/passwords` → экспортируйте пароли в CSV.
2. В приложении нажмите **«Импорт из Chrome CSV»** и выберите файл.

### Копирование паролей

Нажмите на запись в списке, затем кнопку **«Копировать»** — пароль будет скопирован в буфер обмена.

### Удаление паролей и очистка данных

- **Удалить одну запись**: откройте запись → нажмите **«Удалить»**.
- **Очистить все данные**: нажмите **«Очистить»** на главном экране (действие необратимо).

## Хранение данных

Данные хранятся в **LocalStorage браузера** (до ~5 МБ). Статус использования отображается внизу страницы. При заполнении более 80% появляется предупреждение. Рекомендуется регулярно экспортировать данные в JSON для резервного копирования.

## PWA возможности

- **Офлайн-режим**: приложение работает без интернета благодаря Service Worker.
- **Установка как приложение**: в поддерживаемых браузерах (Chrome, Edge) можно установить приложение на устройство через кнопку в адресной строке.
